# ZARVES Android

A starter Android app for a Hindi voice-assistant prototype.

## Current scope
- Tap-to-talk voice input using Android SpeechRecognizer.
- Hindi text-to-speech responses.
- Basic command/response prototype.

## Not implemented yet
- Always-on wake word ("ZARVES"), especially with the screen off.
- Speaker verification / voice-only authorization.
- Reliable automation of phone settings or third-party apps.

This repository is a prototype, not a finished APK.

## Build
Open the Android project in Android Studio and build the `app` debug variant.
